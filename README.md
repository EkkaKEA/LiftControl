# LiftControl

Управление подъемной платформой — тестовое задание.

## Условие

Реализовать программу управления подъемной платформой в среде TIA Portal на языке SCL.

Для контроля зоны перемещения подъемной платформы установлено несколько параллельно включенных датчиков (например, ультразвуковых).

## Компоненты

### Входы (Inputs)

| Вход | Описание                                       | Тип контакта    |
|------|------------------------------------------------|-----------------|
| `I1` | Кнопка «Вверх»                                 | Замыкающий      |
| `I2` | Верхний конечный выключатель                    | Замыкающий      |
| `I3` | Кнопка «Вниз»                                  | Замыкающий      |
| `I4` | Нижний конечный выключатель                     | Замыкающий      |
| `I5` | Ультразвуковые датчики                          | Размыкающий     |
| `I6` | Кнопка «Стоп»                                  | Замыкающий      |
| `I7` | Кнопка аварийного останова                      | Замыкающий      |

### Выходы (Outputs)

| Выход | Описание                      |
|-------|-------------------------------|
| `Q1`  | Платформа вверх               |
| `Q2`  | Платформа вниз                |
| `Q3`  | Предупреждающий световой сигнал |

## Логика работы

### Управление движением

- Подъемная платформа с помощью кнопок может перемещаться вверх или вниз.
- Кнопка «Вверх» подключена к `I1`, кнопка «Вниз» — к `I3`.
- Соответствующее конечное положение распознается концевым выключателем:
  - `I2` — верхнее положение
  - `I4` — нижнее положение
- Если конечное положение достигнуто, двигаться можно только в противоположном направлении.
- С помощью кнопки «Стоп» на `I6` платформу можно остановить.

### Контроль зоны

- Ультразвуковые датчики для контроля зоны перемещения подключены к `I5`.
- Если датчиками распознается препятствие, платформа останавливается.
- Можно перемещать в ручном режиме, если клавиша направления нажата дольше 2 секунд.

### Аварийный останов

- Если нажата кнопка аварийного останова на `I7`, платформа останавливается немедленно.
- Платформа не может перемещаться с помощью кнопок направления, пока не отпущена кнопка аварийного останова.

### Предупредительная сигнализация

- Для лучшего распознавания того, что платформа движется, активизируется предупредительное сигнальное устройство на `Q3`.
- Если платформа движется вверх или вниз, мигает предупредительный световой сигнал на `Q3`.
